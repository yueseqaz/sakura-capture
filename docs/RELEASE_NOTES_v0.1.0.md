## Sakura Capture v0.1.0

Windows x64 便携版。完整解压 `SakuraCapture-windows-x64.zip`，保持两个 EXE 在同一目录，运行 `SakuraCapture.exe`。无需安装 FFmpeg、浏览器或 .NET，无需管理员权限。

### 已包含

- 区域、屏幕、窗口可见区域截图；矩形、箭头、画笔、文字、马赛克、撤销/重做；保存 PNG 并复制到剪贴板。
- 区域/屏幕/窗口区域录屏；MP4/H.264/AAC；系统声音、麦克风、混音和无声模式；帧率与码率选择、鼠标指针、倒计时、暂停/继续和停止保存。
- MyGo 原生中文界面、托盘、自定义全局快捷键、本地历史、单实例运行。
- Windows 高 DPI 清单、应用图标、完整第三方许可证和中文使用说明。

### 已验证

GitHub Windows 构建、Go 测试/竞态检测、原生 GUI 启动、单实例切换、PNG 导出与马赛克像素校验、真实 H.264/AAC 编码和解码均通过。主程序约 9.9 MiB，引擎约 0.34 MiB；云端启动测试工作集约 53 MiB，数值仅作参考。

### 使用边界

- 推荐 Windows 11 x64；Windows N/KN 需要 Media Feature Pack。
- 采用 GDI 屏幕采集，窗口模式固定记录所选屏幕位置，不支持后台/最小化窗口独立捕获。
- 默认音频设备在开始录制时确定；更换设备、锁屏、受保护内容、安全桌面不属于无缝录制场景。
- MP4 需要正常停止才能完成封装；强杀、断电后的文件不保证可恢复。
- 未签名，Windows SmartScreen 可能提示；请核对仓库来源与 SHA256SUMS，不要关闭全局安全防护。
- 此版本标记为预发布，因为真实麦克风、多屏混合 DPI、长时间录制和不同显卡还需要 Windows 硬件验收。不是仅有界面的演示版。

默认快捷键：截图 `Ctrl+Shift+2`，区域录屏 `Ctrl+Shift+3`，停止 `Ctrl+Shift+4`。

详细说明见压缩包内“使用说明.md”，或者仓库 `docs/USER_GUIDE.zh-CN.md`。
