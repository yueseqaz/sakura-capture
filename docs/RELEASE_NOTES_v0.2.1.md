# Sakura Capture v0.2.1

## 界面与操作

- 樱花红 / 暖白原生工作台，统一按钮、卡片、图标、中文字体和操作层级。
- 新版深色置顶录制控制台：计时、暂停/继续、停止并保存，拖动顶部可移动。
- 独立的电脑声音与麦克风实时开关，暂停时也能切换；界面以引擎实际状态为准。
- 关闭声音会释放采集设备；重新开启会获取当前默认设备。无设备或权限被拒时只关闭该来源，不中止画面与其他来源。

## 截图标注

- 圆角深色工具栏、工具高亮、悬停提示、直接点选色板和粗细。
- 新增椭圆、自动递增序号；保留矩形、箭头、画笔、文字、马赛克及撤销/重做。
- 粗细同时控制文字与马赛克大小；Shift 可约束为正方形、正圆、水平/垂直箭头。
- R/A/P/M/T/O/N 切换工具；Enter 保存并复制；Esc 取消。

## 发布包修整

- 修正 Windows 文件属性的版本信息，并在发布构建中校验它与 Git 标签一致。
- 便携包附带 README 引用的界面预览图片，离线查看说明时不再丢图。

## 验证与边界

GitHub Windows 构建覆盖 Go race/vet、原生 GUI 启动、PNG 导出、真实 H.264/AAC 编码解码、解码后的声音开关状态校验，以及暂停期间切换声音和停止保存。

真实声卡的音量/音质、混合 DPI 多屏、长时间音画同步和控制台录制排除效果仍需在 Windows 硬件上验收，因此继续标记为预发布。窗口区域录制仍为固定的可见屏幕区域，不是后台窗口捕获。

下载 `SakuraCapture-windows-x64.zip`，完整解压后运行 `SakuraCapture.exe`；两个 EXE 必须在同一目录。无需安装额外运行时。未签名，可能触发 SmartScreen，请核对来源与 SHA-256，不要关闭安全防护。
