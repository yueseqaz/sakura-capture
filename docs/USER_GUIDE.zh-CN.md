# Sakura Capture 使用说明

## 安装与启动

从 GitHub Actions 的成功构建下载便携压缩包，完整解压后运行 `SakuraCapture.exe`。`sakura-engine.exe` 必须与主程序放在同一文件夹。无需管理员权限，无需安装浏览器或 FFmpeg。

建议 Windows 11 x64；录制控制台的捕获排除需要 Windows 10 2004 或更新版本。Windows N/KN 版本需先安装 Media Feature Pack。当前构建未签名，可能出现 SmartScreen 提示；请核实仓库来源和 SHA-256，不要关闭系统安全防护。

## 常驻悬浮工具栏

启动后直接显示悬浮工具栏，不会默认弹出大主窗口。点击“截图”或“录屏”即可开始；“最近”和“设置”打开辅助主窗口。关闭辅助主窗口后，悬浮栏继续保留。

- 拖动工具栏顶部可移动。拖到屏幕左侧或右侧附近，移开鼠标约一秒后自动收纳为小侧签。
- 悬停侧签展开；点击侧签或在设置中选择“展开并固定工具栏”可保持展开。“收纳”主动贴边。
- 录制开始时控制台保持展开；可手动收纳，侧签保留 REC / 暂停状态，悬停展开后可立即停止。
- 工具栏位置和贴边方向随设置保存；显示器断开后会调整至可见工作区。
- 截图选区期间临时隐藏；取消、完成后自动恢复，不用重新打开主窗口。
- 完整退出请右键系统托盘图标选择“退出”，或点击辅助主窗口右上角“退出”。截图、录制或保存期间请先结束当前操作。

## 截图

- 点击“区域截图”或按 `Ctrl+Shift+2`，拖动选择区域。
- “屏幕截图”：移动鼠标到目标显示器，点击选择。
- “窗口截图”：鼠标指向目标窗口，点击选择其可见屏幕范围。
- 选区完成后出现工具栏：选择、矩形、箭头、画笔、打码、文字、椭圆、序号、直线和高亮。
- **粗细滑块**：连续调整 1–64px；文字显示独立字号（8–64px），马赛克显示块大小。滚轮可以微调。选中已有标注后修改参数立即生效，一次滑块拖动只算一次撤销。
- **当前色按钮**：平时只显示一个色块。点击展开常用色、最近使用色、RGB 滑块和 HEX 输入框；点击 HEX 后直接输入六位颜色值，Enter 应用，Esc 关闭面板。
- **拾色**：点击“拾色”或按 G，放大镜从冻结的截图原图取色，不会采到标注或工具栏。点击应用，Esc 取消。
- **编辑已有标注**：按 V 或点击“选择”，点击对象后拖动移动；拖动角点缩放，箭头/直线可以拖动端点。双击文字重新编辑。Delete 删除，Ctrl+D 复制；方向键微调，Shift+方向键移动 10px。
- **调整截图边界**：选择工具下点击空白处取消对象选择，再拖动选区角点；若需要完全重新框选，点击“重选”。
- **文字**：选择文字工具、点击画面后输入；Enter 完成文字，再次 Enter 保存截图。Esc 先结束文字编辑，不会立刻丢弃整张截图。空文字不保留。
- **复制与保存分开**：“复制”或 Ctrl+C 仅复制图片、不生成文件；“保存”、Ctrl+S 或非文字编辑状态下 Enter 保存 PNG 并同时复制。剪贴板被占用时明确提示，可以重试复制。
- Esc 或“取消”放弃截图。颜色面板、拾色或文字编辑开启时，Esc 先关闭当前操作。右键先返回重新框选，再次右键取消。
- 按 R/A/P/M/T/O/N/L/H 切换矩形/箭头/画笔/马赛克/文字/椭圆/序号/直线/高亮；输入文字时不拦截字母。按住 Shift 绘制正方形、正圆或水平/垂直箭头和直线。
- Ctrl+Z 撤销；Ctrl+Y 或 Ctrl+Shift+Z 重做，覆盖绘制、样式、移动、缩放和删除。
- 输出仅包含选区，不包含选区边框和工具栏。马赛克烘焙到图片像素。

选区可跨显示器；不包含鼠标指针。截图仅支持 PNG，暂不提供滚动长截图和 OCR。

## 录屏

1. 选择声音：无声音、系统声音、麦克风或系统＋麦克风。声音来源是 Windows 默认设备。
2. 选择 15/30/60 FPS 和码率档位。建议先用 30 FPS、标准画质。
3. 点击“区域录屏”“屏幕录屏”或“窗口区域录屏”，选择范围。
4. 根据设置等待 0/3/5 秒（倒计时期间可取消），出现录制控制条后开始录制。
5. 深色悬浮控制台可以暂停、继续、独立开关电脑声音与麦克风，或停止并保存。拖动顶部区域可移动控制台；也可按 `Ctrl+Shift+4` 停止。声音开关在暂停期间也可用，不会改变下一次录制的默认设置。
6. 等待 MP4 封装完成，同一个悬浮栏恢复截图/录屏入口；点击“最近”打开录像。

普通模式下，控制台沿用常驻悬浮栏的位置，在所在屏幕工作区内置顶显示，并启用 Windows 捕获排除。显示之前会核验该设置；如果系统不支持或无法确认，软件会取消本次录制并提示原因，而不是隐藏控制台继续录。启动编码器时显示“正在启动录制…”，收到引擎就绪确认后才显示“正在录制”。停止后解除捕获排除。此设置不只影响本软件，也会影响远程桌面/云电脑的画面传输。

### 云电脑 / 远程桌面出现黑块

Windows 的捕获排除可能被远程传输软件解释为隐藏窗口或黑色矩形。Windows 接口确认设置成功，并不代表第三方云电脑会正确显示它。

- v0.3.1 起，待机悬浮栏不再启用捕获排除，录制结束后也会解除。仅打开程序或截图时无需开启任何兼容开关。
- 如果录制时在云电脑里看不到控制台，到“设置 → 桌面悬浮工具栏”开启“云电脑 / 远程桌面兼容（录制控制台可能入镜）”。该选项立即保存，下次录制生效；录制过程中不能切换。
- 兼容模式关闭捕获排除，让远程传输可以显示控制台。但它位于录制范围内时也会被录入。请使用区域录屏，并把控制台放到选区外；整屏录制不能保证同时远程可见且不入镜。录制控制台顶部会持续显示此模式的警告。
- 本更新没有对 3060 云电脑做直接服务端验收；若仍出现黑块，请反馈待机还是录制时出现，以及 Windows 版本。普通模式仍保留不入镜检查。

声音开关的状态来自引擎确认，不是按钮的假状态。关闭某个来源会停止对应设备采集；重新开启会打开当前默认设备。无设备、麦克风权限被拒或设备中途断开时，只关闭对应来源并在控制台提示，画面和另一声音来源继续录制。重新连接设备后可以再次点击开启。即便以“无声音”开始，之后仍能开启声音；为此 MP4 始终保留 AAC 轨道，两个来源都关闭时写入静音。

系统与麦克风混音时各采用 50% 增益，避免直接相加削波。不会做麦克风降噪或回声消除；建议使用耳机避免麦克风重复收录扬声器声音。

**窗口区域录屏是固定屏幕坐标录制**：窗口移动、最小化或被其他窗口遮挡后，会录入该屏幕位置实际显示的内容。不是独立后台窗口捕获。请选择稳定的窗口位置。

录制中不应锁屏、休眠、切换默认音频设备或强制结束进程。正在保存时请勿退出。遇到声音设备错误只停用该来源；遇到编码或存储错误会结束录制并显示错误，已产生的部分文件不保证完整或可播放。

## 托盘与快捷键

关闭主窗口后程序仍保留悬浮栏与托盘，可以继续使用快捷键。单击托盘图标打开窗口，右键菜单可以截图、录屏、停止或退出。

默认快捷键：

| 操作 | 默认按键 |
| --- | --- |
| 区域截图 | Ctrl+Shift+2 |
| 区域录屏 | Ctrl+Shift+3 |
| 停止录屏 | Ctrl+Shift+4 |

在“设置”中修改后，点击“保存设置并应用快捷键”。若提示被占用，请换一个组合。活动截图和录屏结束后才能退出。

## 文件与隐私

默认保存在用户的 `Pictures/Sakura Capture` 目录，可以改为其他文件夹。不上传、不登录、不包含分析上报。

“最近文件”只保存路径，不额外复制文件。清空历史不会删除原图片或录像。配置与历史位于 `%APPDATA%/SakuraCapture/settings.json`；每种标注工具的粗细、颜色与最近色保存在同目录的 `editor.ini`。删除 `settings.json` 恢复主程序默认设置；删除 `editor.ini` 恢复标注偏好。这些操作不删除媒体文件。

## 常见问题

- 缺少引擎：不要只复制 `SakuraCapture.exe`，请完整解压。
- 更新后仍像旧版：先从系统托盘彻底退出旧程序，再运行新版；仅关闭主窗口不会退出。
- 无麦克风：检查默认输入设备，以及“设置 → 隐私和安全性 → 麦克风 → 允许桌面应用访问麦克风”。
- 无系统声音：先确认 Windows 有默认扬声器/耳机设备，实际播放了声音。
- 黑屏：不支持受保护内容、安全桌面和部分独占全屏。请改用普通桌面窗口。
- 画面卡顿：改为 30 或 15 FPS，缩小录制区域，关闭其他高负载程序。
- 文件不可播放：正常停止才能完成 MP4 封装；断电和强杀进程不保证可恢复。

此版本的自动测试覆盖配置、原生界面及真实媒体编码/解码。真实多屏、声音设备与显示驱动仍需按 `WINDOWS_QA.md` 在 Windows 电脑验收。
