# Sakura Capture v0.2.2

## 修复

- 修复引擎启动参数意外隐藏截图选区窗口，导致屏幕截图或录制选区无法完成的问题。
- 录制控制台在编码器初始化之前显示，始终置顶，并放置在所选屏幕的可见工作区。
- 显示控制台之前设置并核验 Windows 录制排除属性；无法确认时取消录制，不冒险把控制台录入视频。需要 Windows 10 2004 或更新系统。
- 标注工具栏明确显示颜色与 3px / 6px / 9px 粗细按钮；新绘制的标注可立即修改样式，也可按 V 选择已有标注后修改。
- 已有标注的颜色、粗细调整支持撤销和重做；修复右键重选后残留撤销记录的问题。
- 多屏环境下标注工具栏限制在选区所在屏幕内；无效选区返回明确错误，不再静默结束。

## 验证范围

新增 Windows 实际窗口交互测试：显示和点击截图选区、保存 PNG、修改已有标注并检查导出像素、从主界面开始录制、检查悬浮控制台置顶与捕获排除、点击暂停/继续/停止并解码输出 MP4。此前仅界面渲染和编码测试不足以覆盖这次窗口启动问题。

真实麦克风/扬声器设备、混合 DPI 多显示器和各类显卡驱动仍需在实体 Windows 电脑上验收。Windows 的窗口录制排除不是对外部摄像机或所有第三方捕获方式的隐私保证。

## 使用

完整解压 `SakuraCapture-windows-x64.zip`，将两个 EXE 保持在同一目录，运行 `SakuraCapture.exe`。不要只替换主程序而保留旧版 `sakura-engine.exe`。
